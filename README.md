# Тестовый Telegram-бот

Это отдельный учебный проект. Он не связан с репозиторием `bulls-and-cows`.

## Что умеет бот
- Отвечает на команду `/start`.
- Повторяет обычное текстовое сообщение.

## Запуск
1. Установить зависимости: `pip install -r requirements.txt`.
2. Задать переменную окружения `BOT_TOKEN` со значением токена от BotFather.
3. Запустить: `python bot.py`.

**Важно:** не добавляйте токен в файлы проекта и не публикуйте его в GitHub.
